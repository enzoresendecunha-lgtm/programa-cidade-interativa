# Cidade Interativa — site (front-end)

Site estático: `index.html`, `livro.html`, `terreno.html` + scripts e imagens.

## Como editar
Edite os arquivos, abra `index.html` no navegador para conferir e envie por Pull Request na `main`.

## O que NÃO está neste repositório (de propósito)
O cadastro, o banco de dados, o envio de e-mail e as páginas restritas do livro rodam num
back-end hospedado pela LSC-Lab. O site chama esse back-end em `/api/...`.
**Não altere** os endereços `/api/...` nem os campos dos formulários sem alinhar com a LSC-Lab.

## Publicação
Mudanças aprovadas na `main` são publicadas pela LSC-Lab.
